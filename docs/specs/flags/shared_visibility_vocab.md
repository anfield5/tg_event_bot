# Общий словарь: `visible` / `hidden` / `onlycount`

Используется флагами [`-wl`](./wl_waitlist.md) и [`-ngl`](./ngl_notgoinglist.md).
Общая идея одна и та же — три уровня детализации списка в посте. Точное поведение каждого уровня описано в файле конкретного флага (у `-wl` есть нюанс с разделением хаб/дочерний чат, у `-ngl` его нет).

| Значение | Общий смысл |
|---|---|
| `visible` | Список показывается полностью — с именами |
| `onlycount` | Показывается только число, без имён |
| `hidden` | Секция не отображается в посте вовсе |

**Важно:** `hidden` ≠ "функция выключена". Механика (сбор в очередь / учёт Not Going) продолжает работать всегда — флаг влияет только на то, что видно **в посте**. Для Waitlist есть отдельный путь просмотра вне поста — команда `/waitlist` (admin-only), которая игнорирует этот флаг полностью.

**Регистр:** значения нечувствительны к регистру при вводе (`-wl VISIBLE` работает так же, как `-wl visible`), но хранятся в БД в нижнем регистре.
