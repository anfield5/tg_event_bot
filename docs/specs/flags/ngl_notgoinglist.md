# Флаг: `-ngl` / `-notgoinglist`

**Используется в:** [`/newevent`, `/editevent`](../commands/newevent_editevent.md) (в `/shareevent` есть свой override — `-sngl`, см. спек команды)
**Синтаксис:** `-ngl visible|hidden|onlycount` (или `-notgoinglist ...`)
**Тариф:** не гейтится, доступен на любом тарифе
**Дефолт:** `visible`, если флаг не указан
**Значения:** см. [общий словарь `visible`/`hidden`/`onlycount`](./shared_visibility_vocab.md)

---

## Назначение

Управляет отображением списка "Not Going" в посте события.

## Детальное поведение по значениям

1. **`visible`** (дефолт) — список показывается полностью, с именами. Это поведение, которое было **до** появления этого флага — старые события без явного значения ведут себя так же.
2. **`onlycount`** — показывается только число, без имён.
3. **`hidden`** — секция "Not Going" полностью отсутствует в посте (не просто пустая — заголовок тоже не рендерится).

## Отличие от `-wl`

В отличие от `-wl`, у `-ngl` **нет** различия между хабом и дочерним чатом — "Not Going" всегда локальна для того чата, где кликнули (нет концепции cross-chat агрегации, в отличие от Waitlist).

## Важный нюанс — не гейтится

В отличие от `-wl` и `-clc`, этот флаг **доступен на любом тарифе**, включая FREE. Причина — список "Not Going" существовал и был виден всем ещё до появления самого флага; флаг лишь добавил возможность скрыть/сократить его, не ограничивая доступ к базовой функциональности.

## Взаимодействие с другими флагами

- **[`-clc`](./clc_clickability.md)**: отдельно решает, кликабельны ли имена внутри списка Not Going.
- **`/shareevent -sngl`**: per-share override для конкретного дочернего чата.

## Тест-сценарии

- [ ] **T1 — Дефолт.** `/newevent Party` без `-ngl` → `notgoing_visibility = 'visible'`.
- [ ] **T2 — Явный выбор.** `/newevent Party -ngl hidden` → `notgoing_visibility = 'hidden'`.
- [ ] **T3 — Отсутствие гейтинга.** FREE-хаб, `-ngl hidden` → применяется **без** ошибки о тарифе (в отличие от `-wl`/`-clc`).
- [ ] **T4 — `hidden`: рендер.** Есть 2 человека в Not Going → пост **не содержит** ни секции, ни заголовка "Not Going".
- [ ] **T5 — `onlycount`: рендер.** 3 человека в Not Going → показывается только число `3`, без имён.
- [ ] **T6 — `visible`: рендер.** Список показывается полностью с именами, идентично поведению до появления флага.
- [ ] **T7 — Локальность, без cross-chat.** Событие расшарено в дочерний чат, там кто-то нажал Not Going → это **не** отражается в Not Going-списке хаба и наоборот (в отличие от Waitlist с `-wl visible`, где хаб видит все чаты).
- [ ] **T8 — Per-share override.** Событие `-ngl visible`, дочерний чат расшарен с `-sngl hidden` → именно этот дочерний чат скрывает Not Going, хаб продолжает показывать полный список.
- [ ] **T9 — Изменение на лету.** Событие открыто с `-ngl visible` → `/editevent -ngl hidden` → пост обновляется, секция исчезает при следующем рендере.
